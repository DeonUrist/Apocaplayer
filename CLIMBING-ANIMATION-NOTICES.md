# Animation sources

The two climbing clips come from Epic Games' Game Animation Sample on Fab:
https://www.fab.com/listings/880e319a-a59e-4ed2-b268-b32dac7fa016

The project owner confirmed that their acquisition is under the Fab Standard
License. The imported Humanoid clips are incorporated into the Apocaplayer climbing
animation AssetBundle. The original project and the exported source FBX files
are not part of the mod package. Do not redistribute the source animations as
standalone assets. Licence: https://www.fab.com/eula

The detector, collision checks, movement state and Apocaplayer integration are
new C# implementations. No Unreal Blueprint or engine runtime code is bundled.
